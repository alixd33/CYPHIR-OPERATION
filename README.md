# OPERATION: CIPHER v2.2.8 — Desktop PC Visual Slice

نسخهٔ توسعهٔ دسکتاپ OPERATION: CIPHER با تمرکز این شاخه بر ارتقای محیط Pixel Art سه‌ربع، یکپارچگی دیوارها و تناسب ابعاد آبجکت‌ها.

> این بسته از شاخهٔ کاری `work/atrium-visual-slice` ساخته شده است؛ Pull Request مربوط به آن هنوز Draft است و تغییرات به `main` ادغام نشده‌اند.

## تغییرات بصری این نسخه

- حفظ شبکهٔ اصلی جهان با کاشی‌های 16×16.
- اصلاح متادیتای Tilesetهای HQ و Server Room مطابق ابعاد واقعی تصاویر.
- رسم آبجکت‌ها با برش ناحیهٔ غیرشفاف و حفظ نسبت تصویر؛ بدون کشیدگی افقی یا عمودی.
- یکسان‌سازی پروفایل بصری دیوارهای افقی و عمودی، شامل کلاهک، نمای جانبی و اتصال گوشه‌ها.
- تکمیل فرش مرکزی آتریوم با حاشیه‌های چندلایه.
- افزودن جزئیات پراکنده و قطعی به سطوح کف، با رنگ‌بندی جداگانه برای HQ و Server Room.
- انتقال نورهای موضعی به لایهٔ کف تا روی شخصیت‌ها و مبلمان قرار نگیرند.

## اجرای بازی در Windows 10/11

1. فایل ZIP را در یک پوشه استخراج کن.
2. Node.js نسخهٔ 18 یا جدیدتر را نصب کن.
3. فایل `start-cipher.bat` را اجرا کن؛ سرور محلی شروع می‌شود و مرورگر باز خواهد شد.
4. برای بستن سرور، `stop-cipher.bat` را اجرا کن.

اجرای دستی از ترمینال:

```bash
npm start
```

آدرس پیش‌فرض سرور: `http://127.0.0.1:4173`

## آزمون‌ها

```bash
npm test
npm run test:e2e
```

- `npm test` مجموعهٔ تست‌های واحد، موتورهای بازی و کنترل‌های بصری را اجرا می‌کند.
- `npm run test:e2e` به محیط Chromium نیاز دارد؛ اجرای آن برای این بسته در محیط Windows واقعی انجام نشده است.

## محدوده و وضعیت

- هدف این نسخه: Desktop PC با ماوس و صفحه‌کلید؛ موبایل خارج از محدودهٔ فعلی است.
- تغییرات این شاخه به سیستم ذخیره‌سازی، پیشرفت کمپین یا سیاست تایمرها دست نمی‌زنند.
- این بسته یک Visual Slice توسعه‌ای است، نه اعلام تکمیل نسخهٔ نهایی بازی.
